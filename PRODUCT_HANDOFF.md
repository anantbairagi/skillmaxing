# Product handoff

Give this file to a new teammate. It is the onboarding guide. Day-to-day engineering rules are in [AGENTS.md](AGENTS.md).

## Product

Skillmaxing study build: a static website for three sequenced engineering courses, plus labs, a 36-paper reading order, a daily brief, a short blog, and a sample news desk. Accounts, progress, and plans stay in the browser. The look follows [skillmaxing.xyz](https://skillmaxing.xyz/). Lesson prose and lesson videos are original to this repository. The course assistant and payments are intentionally absent.

Shipped behavior is listed in [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md). A coverage checklist is in [COVERAGE.md](COVERAGE.md).

### Getting write access

Do not add yourself. Ask `anantbairagi` to invite your GitHub user with the smallest role that fits:

| Need | Role |
| --- | --- |
| Read issues and clone | none (the repo is public) |
| Open branches and pull requests from a fork | none |
| Push branches in this repo | Write |
| Manage settings or secrets | Admin, only for the owner |

The owner must approve the invite. Agents must not send invites or change security settings.

## Set up a laptop

Requirements: Git, Node.js 22, npm. No database, no API keys.

```bash
npm ci
npm test
npm run dev
```

Open http://localhost:3000/. Production paths use the `/skillmaxing` prefix. Local dev does not, unless you set `NEXT_PUBLIC_BASE_PATH`.

Copy env only if you need the prefix locally:

```bash
cp .env.example .env.local
```

`.env.example` has placeholders only. This app has no API keys. Do not create cloud credentials for it.

Sign in from `/login/` with **Use local demo account**. The password is a client-side constant in `lib/store.tsx`, not a hosted secret. Do not paste it into docs, issues, or chat logs.

## Services you do not need

There is no database console, payment dashboard, email provider, or model API. Newsletter addresses, reset codes, and profiles never leave the browser. Nothing in this repo calls skillmaxing.xyz.

## Working with AI agents

Point the agent at [AGENTS.md](AGENTS.md) and at this file. Cursor also loads `.cursor/rules/agents.mdc`. Claude Code reads `CLAUDE.md`. Copilot reads `.github/copilot-instructions.md`. Those files only point back at `AGENTS.md`.

Tell the agent the issue or PR number, the branch you expect, and what not to build (assistant, payments, reference videos). Review the PR yourself. Agents do not merge by bypassing CI.
